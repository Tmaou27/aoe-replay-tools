# MGX → воспроизведение → overview

Для Windows 11 и проверенной сборки age2_x1.exe VEG MOD. MGX задаёт имя и контрольную сумму исходной записи. Состояния берутся из работающей игры во время воспроизведения. Самостоятельного движка MGX здесь нет; открытие записи и подтверждение её окончания пока ручные.

## Запуск

Распакуйте папку aoe_from_mgx в C:\Users\dream\Downloads\aoe_trace, рядом с вашей .venv. Используется установленная там Frida. Если её нет:

```powershell
.venv\Scripts\python.exe -m pip install frida
```

1. Откройте нужный MGX в привычной версии игры. Поставьте паузу максимально близко к началу. Должен работать один age2_x1.exe.
2. В PowerShell из aoe_trace запустите:

```powershell
.venv\Scripts\python.exe .\aoe_from_mgx\generate.py "C:\путь\game.mgx"
```

3. Дождитесь приглашения и нажмите Enter в консоли. После сообщения «Снимите паузу записи» продолжите воспроизведение в игре.
4. Дождитесь окончания записи, НЕ закрывайте игру. Вернитесь в PowerShell и нажмите Ctrl+C один раз. Дождитесь обработки: программа завершит сбор, проверит лог, сожмёт его и откроет HTML.

По умолчанию сбор ограничен четырьмя часами реального времени. Например, `--seconds 28800` задаёт восемь часов. Это не определение конца партии. Несколько процессов: добавьте `--pid 35280`, подставив текущий PID. Если доступ запрещён, права консоли должны соответствовать правам игры; не отключайте защиту системы. EXE с другим SHA256 отклоняется до установки перехватов.

## Результат

Новая папка aoe_result_дата_время_суффикс содержит:

- capture.jsonl — исходный лог, не удаляется автоматически;
- capture.zip — его сжатая копия;
- overview.html — автономный обзор v3: ресурсы, счёт, состав, карта, сравнение выбранного подмножества игроков, группы армии и произвольные комбинации типов;
- manifest.json — SHA256 входного MGX, записанный интервал, диагностика доставки и ограничений.

Не закрывайте консоль при сжатии и построении. Для длинных игр нужны свободные диск и память: JSONL, ZIP и HTML хранятся одновременно. Снимки объектов записываются примерно раз в игровую секунду. По умолчанию HTML сохраняет все снимки. При необходимости добавьте `--sample-seconds 10`: HTML оставит первый снимок и последний снимок каждого десятисекундного интервала. Короткие события между точками могут быть не видны; исходный лог остаётся неизменным. Частота показана в обзоре.

## Перестроение без повторного прогона

Из JSONL (MGX нужен только для привязки и хеша):

```powershell
.venv\Scripts\python.exe .\aoe_from_mgx\generate.py "C:\путь\game.mgx" --log "C:\путь\capture.jsonl" --sample-seconds 10
```

Или только HTML из JSONL/ZIP, без MGX:

```powershell
.venv\Scripts\python.exe .\aoe_from_mgx\viewer\build.py "C:\путь\capture.zip" --out "C:\путь\overview_new.html"
```

Выходной HTML не должен существовать. `--no-open` у generate.py отключает открытие браузера. `--output-dir` задаёт новую папку результата.

## Точность и границы

Сохраняются фактические снимки памяти, а не расчётные затраты по командам MGX. Однако совпадение открытой записи с переданным MGX и достижение конца партии автоматически НЕ проверяются; это явно отмечено в manifest.json. Пропущенное до подключения время восстановить нельзя. Лимиты перехватов и ошибки отражаются в диагностике; частичный обзор не является подтверждением полного прогона.

Счётчики ресурсов и состав привязаны к снимкам. Не все изменения между снимками представлены на графиках. Кандидаты полей гарнизона и часть характеристик не подтверждены. Действия подробно отслеживаются только для поддержанного типа задач сборщика: отсутствие действия в логе не означает простой. Названия основаны на справочнике AoC; модифицированные типы могут требовать уточнений. Классификацию групп можно менять в просмотрщике.

Сборщик использует Frida и перехваты внутри процесса, поэтому это экспериментальная инструментализация офлайн-повтора, не пассивное чтение файла. Проверка SHA256 привязана к исследованному EXE:
4ffd2e0aa42871b0d1812b994e8b98af0cae489eb89e947c592d034ef317e7fc

Программный запуск игры, автоматический выбор MGX и автоматическое распознавание конца партии в эту версию не входят.
