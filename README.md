# AoE Replay Tools

Инструменты для разбора записанных партий **Age of Empires II: The Conquerors (VEG MOD)**. С ними можно сравнить экономику и армии игроков по времени, найти переломный момент и понять, какой отрезок повтора стоит пересмотреть.

| Папка | Что делает |
| --- | --- |
| [aoe_from_mgx](aoe_from_mgx/README.md) | Собирает снимки состояния во время воспроизведения MGX и строит интерактивный обзор ресурсов, счёта, состава войск и позиций объектов. |
| [aoe_coach](aoe_coach/README.md) | Читает готовый лог и отмечает эпизоды для разбора, например падение числа жителей, рост запасов без прироста армии или ухудшение соотношения численности. |

## Подготовка

Для записи нужен Windows, Python, Frida и совместимая сборка `age2_x1.exe` VEG MOD. Сборщик проверяет SHA-256 исполняемого файла перед установкой перехватов. Совместимая сборка указана в [документации сборщика](aoe_from_mgx/README.md).

Откройте PowerShell в корне проекта. Если `.venv` уже создана и Frida установлена, переходите к записи.

```powershell
py -m venv .venv
.venv\Scripts\python.exe -m pip install frida
```

Для обработки готового лога достаточно Python 3.9+. Можно использовать обычный `python` вместо пути к `.venv`. Запуск игры и установка Frida нужны только для записи.

## Записать партию и построить обзор

1. Откройте нужную запись MGX в игре и поставьте её на паузу как можно ближе к началу.
2. Выполните команду, подставив путь к тому же файлу. Одинарные кавычки сохраняют обратные кавычки, которые могут встречаться в имени записи.

   ```powershell
   .venv\Scripts\python.exe .\aoe_from_mgx\generate.py 'C:\Games\SaveGame\game.mgx' --sample-seconds 10
   ```

3. Когда сборщик попросит, нажмите **Enter** в PowerShell. После сообщения о начале сбора снимите паузу в игре.
4. По окончании повтора оставьте игру открытой, вернитесь в PowerShell и нажмите **Ctrl+C один раз**. Дождитесь сжатия лога и открытия обзора.

В папке `aoe_result_…` появятся `capture.jsonl` (исходный лог), `capture.zip` (сжатая копия), `overview.html` (обзор) и `manifest.json` (интервал сбора и диагностика). В обзоре выберите игроков, группу войск или конкретные типы юнитов. Ползунок времени показывает состав и позиции в выбранный момент.

В примере `--sample-seconds 10` уменьшает размер HTML, сохраняя первый снимок и последний снимок каждого десятисекундного интервала. Короткие изменения могут оказаться между точками обзора. Исходный лог сохраняет все записанные снимки.

Если обзор получился слишком большим, перестройте его из архива. Подставьте фактический путь к ZIP и выберите свободное имя HTML.

```powershell
.venv\Scripts\python.exe .\aoe_from_mgx\viewer\build.py 'C:\Logs\capture.zip' --out '.\overview_30s.html' --sample-seconds 30
```

## Разобрать партию из готового лога

Подайте `capture.zip` или `capture.jsonl` со снимками состава. Укажите свой номер игрока и номера соперников из обзора.

```powershell
.venv\Scripts\python.exe .\aoe_coach\analyze.py 'C:\Logs\capture.zip' --player 1 --opponents 2 3 --out '.\coach.html'
```

Откройте `coach.html` в браузере. Соседний `coach.json` содержит данные отчёта. Оба выходных имени должны быть свободны. По умолчанию анализ сравнивает снимки за окно примерно в минуту игрового времени. Чтобы изменить окно, добавьте, например, `--window 120`.

Выберите один эпизод и пересмотрите повтор, начав немного раньше указанного времени. Например, если запас дерева рос, а число кораблей стояло на месте, проверьте доки, лимит населения и недавние столкновения. Если увидите, что производство действительно упёрлось в лимит, попробуйте в следующей партии поставить дома раньше и проверьте, исчезла ли задержка.

## Как читать результаты

- Сбор идёт из запущенной игры. Открытие нужной записи и остановка сбора выполняются вручную. В `manifest.json` можно проверить, какой интервал попал в лог.
- Изменение численности показывает разницу между снимками. Её могут объяснить потери, обращение юнитов или особенности учёта гарнизона. Состав, улучшения и позиции помогают оценить, у кого было преимущество в конкретном бою.
- Сигналы в `coach.html` основаны на порогах. Используйте их как указатели для просмотра повтора. Причину эпизода проверяйте в игре с учётом того, что было видно игроку в тот момент.
